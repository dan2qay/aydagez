# Идеи и их статус

Список идей владельца продукта с отметкой, что сделано и где это смотреть. Обновлено 22.10.2026.

| Идея | Статус | Где смотреть |
|---|---|---|
| Логирование действий: переходы, UTM-метки, работа маркетолога | Сделано | Сессии с UTM, реферером и страницей входа пишутся с первого визита; экран для маркетолога `#/stats` (источники, кампании, воронка, запросы, запросы без результата) |
| Личные кабинеты как на Авито, сеансы «от и до» | Сделано раньше | `#/my`, `#/cabinet`, сеансы сворачиваются в одну карточку |
| Все календари в одном стиле | Сделано | Один компонент календаря в ленте, листе «Даты» и всех полях даты в формах |
| Личный кабинет с фото и описанием, регистрация человек/организация | Сделано раньше | `#/my`, окно «Представьтесь» |
| Любой бюджет | Сделано раньше | Панель «Фильтры», гистограмма цен |
| Фильтры как у Airbnb/Авито, виды спорта, ИИ понимает | Сделано раньше | Панель «Фильтры», `server/facets.js` |
| «Хочу поиграть в волейбол» ищет волейбол, а не командный спорт | Сделано | Конкретное занятие отсекает остальные (`STRICT_ACTS`), короткие маркеры совпадают только с началом слова; сценарии в `server/scenarios.js`, `npm run ai:test` |
| Кино: один фильм не забирает выдачу, сеансы по фильтру, возраст у всех событий | Сделано | Фильм = одна карточка в день; в режиме «Все дни» серия показывается один раз с пометкой «ещё N дат»; при времени в запросе в карточке только подходящие сеансы; у каждого события маркировка 0+…18+ |
| Куда сходить с коллегами — не только ИТ | Сделано раньше | Разнообразие выдачи |
| Аналитика ИИ-поиска и интеграция с Алисой | Сделано, нужна регистрация навыка | Доля ИИ-разбора и модели в `#/stats`; навык Алисы `POST /api/alice` со ссылками на запись `?utm_source=alice`; страницы `/e/<событие>` с разметкой schema.org и `sitemap.xml` для Яндекса и ИИ-ассистентов. Как зарегистрировать навык — `docs/growth.md` |
| Вход через Яндекс, Google, Госуслуги | Яндекс и Google сделаны, нужны ключи; Госуслуги позже | `/auth/yandex`, `/auth/google`; Госуслуги требуют регистрации системы в ЕСИА — см. `docs/growth.md` |
| Календарь на телефоне, «выходные» без календаря | Сделано раньше | Лента дней и лист «Даты» |
| Правила пользования площадкой | Черновик готов, нужен юрист | `#/rules` (`public/legal/rules.md`), согласие при регистрации и публикации, кнопка «Пожаловаться», модерация жалоб в `#/stats` |
| «Можно с детьми» при создании события и детские события | Сделано | Поля «Возраст» и «Можно с детьми» в разделе «Что и где»; раздел «Детям» (спектакли, мастер-классы, кружки, спорт, шоу, мультфильмы); фильтр «Возраст ребёнка»; фраза «с ребёнком 5 лет» отсекает 6+ |
| Можно с детьми и с собаками | Сделано | Переключатели «Можно с детьми» и «Можно с собаками» в разделе «Главное» формы; плитка «С собакой», фильтр «С кем идёте → С собакой», фраза «погулять с собакой» показывает только места, куда пускают с собаками; метка «можно с собакой» на карточках |
| Telegram-приложение, запись через Telegram и MAX | Сделано: запись по ссылке; бота нужно создать в BotFather | Если у организатора или события указан Telegram/MAX, кнопка «Записаться» открывает чат с ним, событие попадает в «Записи». Сайт работает как мини-приложение Telegram (`?tg=1`). Инструкция — `docs/telegram.md` |
| Таймлайн занятости проката, как в Teams | Сделано | На странице проката — шкала дня: каждый час виден свободным, почти занятым или занятым, с числом свободных мест; клик переключает час |
| Первая страница — сразу список мероприятий, категории по нажатию на поиск | Сделано | Главная — лента событий (поиск → даты → выдача); при нажатии на строку поиска открывается панель «Знаем, чем вам заняться» с плитками |
