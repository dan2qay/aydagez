# Мини-приложение Telegram и запись через мессенджеры

## Запись через Telegram и MAX

Пока без CRM: кнопка «Записаться» ведёт в чат организатора, а событие добавляется гостю в «Записи» с напоминанием за 24 часа.

- Организация указывает Telegram и MAX в кабинете → «Профиль». Тогда на всех её событиях с записью «у нас» вместо обычной кнопки появляются «✈️ Записаться в Telegram» и «💬 Записаться в MAX».
- Для отдельного события контакты можно задать в форме создания: «Подробнее» → «Telegram для записи», «MAX для записи» (`events.meta.tg`, `events.meta.max`). Они важнее контактов организации.
- Переходы в мессенджеры считаются в аналитике как события `messenger_click` с полем `via`.

## Мини-приложение в Telegram

Сайт сам подстраивается, когда открыт внутри Telegram: подключает SDK Telegram, разворачивается на весь экран, берёт тёмную тему из Telegram, показывает системную кнопку «Назад» на страницах события и организации, а ссылки на t.me открывает внутри Telegram.

Как подключить бота:

1. В @BotFather: `/newbot` → имя «Айдагез», ник, например `aydagez_bot`.
2. `/mybots` → бот → Bot Settings → Menu Button → URL `https://<домен>/?tg=1`, текст «Афиша».
3. Для отдельной ссылки на приложение: `/newapp` → тот же URL. Ссылка вида `https://t.me/aydagez_bot/app`.
4. Домен должен открываться по HTTPS (Railway даёт его автоматически).

SDK грузится с telegram.org только внутри Telegram; в обычном браузере внешние скрипты не подключаются.

## MAX

Мини-приложения MAX подключаются так же — URL сайта в настройках бота MAX. Отдельная интеграция с SDK MAX не нужна для записи по ссылке; её стоит добавить, когда появится запись внутри платформы.
